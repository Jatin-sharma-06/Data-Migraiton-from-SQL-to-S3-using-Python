☁️ Part 1: AWS Setup

1. Create S3 Bucket

Step 1 Click Services → select S3 → click Create Bucket.

Step 2 Enter the Bucket name (e.g. tpci-zendesk-attachments), scroll down and click Create Bucket.

🖼️ AWS S3 Console – Create Bucket

2. Create IAM Policy

Step 1 Navigate: Services → IAM → Policies → Create Policy.

Step 2 Switch to the JSON tab and paste the policy below. Click Next.

📄 data-migration-policy.json
{ "Version": "2012-10-17", "Statement": [ { "Effect": "Allow", "Action": [ "s3:ListBucket" ], "Resource": "arn:aws:s3:::tpci-zendesk-attachment" }, { "Effect": "Allow", "Action": [ "s3:GetObject", "s3:DeleteObject", "s3:PutObject" ], "Resource": "arn:aws:s3:::tpci-zendesk-attachment/*" } ] }
⚠️ Note: Replace tpci-zendesk-attachment with your actual bucket name.

Step 3 Enter the policy Name and Description, then click Create policy.

3. Create IAM Role

Step 1 Navigate: Services → IAM → Roles → Create Role.

Step 2 Select Trusted entity type: AWS Service and Use Case: Lambda. Click Next.

Step 3 Attach the following policies:

  • Data-migration-policy (created above)
  • AWSLambdaBasicExecutionRole

Step 4 Click Next, enter a Role Name (e.g. Data-migration-permission-role), and click Create Role.

5. Create Lambda Functions

Create 4 Lambda functions using the same IAM execution role (Data-migration-permission-role). Each function needs the environment variable BUCKET_NAME set to your S3 bucket name.

5.1 listFilesForRecord

📄 index.mjs
import { S3Client, ListObjectsV2Command, HeadObjectCommand } from "@aws-sdk/client-s3"; const s3 = new S3Client({}); const BUCKET_NAME = process.env.BUCKET_NAME; export const handler = async (event) => { try { const zendeskId = event.queryStringParameters?.zendeskId || event.zendeskId; if (!zendeskId || zendeskId.trim() === "") { return respond(400, { error: "zendeskId is required." }); } const prefix = `${zendeskId}/`; const command = new ListObjectsV2Command({ Bucket: BUCKET_NAME, Prefix: prefix, }); const result = await s3.send(command); const rawFiles = (result.Contents || []).filter( (obj) => obj.Key !== prefix && obj.Size > 0 ); const files = await Promise.all( rawFiles.map(async (obj) => { let zendeskTicketCreateDate = null; try { const head = await s3.send(new HeadObjectCommand({ Bucket: BUCKET_NAME, Key: obj.Key, })); zendeskTicketCreateDate = head.Metadata?.["zendesk-ticket-create-date"] || null; } catch (headErr) { console.error(`HeadObject failed for ${obj.Key}:`, headErr); } return { fileName: obj.Key.replace(prefix, ""), fileSizeBytes: obj.Size, lastModified: obj.LastModified, key: obj.Key, zendeskTicketCreateDate: zendeskTicketCreateDate, }; }) ); return respond(200, { files, count: files.length }); } catch (err) { console.error("List files error:", err); return respond(502, { error: "Unable to list files right now. Please try again." }); } }; function respond(statusCode, body) { return { statusCode, headers: { "Content-Type": "application/json", "Access-Control-Allow-Origin": "*" }, body: JSON.stringify(body), }; }

5.2 previewFile

📄 index.mjs
import { S3Client, GetObjectCommand } from "@aws-sdk/client-s3"; import { getSignedUrl } from "@aws-sdk/s3-request-presigner"; const s3 = new S3Client({}); const BUCKET_NAME = process.env.BUCKET_NAME; export const handler = async (event) => { try { let body; try { body = event.body ? JSON.parse(event.body) : event; } catch { return respond(400, { error: "Invalid request body." }); } const { zendeskId, s3Key, disposition } = body; if (!zendeskId || !s3Key) { return respond(400, { error: "zendeskId and s3Key are required." }); } const expectedPrefix = `${zendeskId}/`; if (!s3Key.startsWith(expectedPrefix)) { return respond(403, { error: "Invalid file reference." }); } const safeFileName = s3Key.split('/').pop(); const contentDisposition = disposition === 'attachment' ? `attachment; filename="${safeFileName}"` : `inline; filename="${safeFileName}"`; const command = new GetObjectCommand({ Bucket: BUCKET_NAME, Key: s3Key, ResponseContentDisposition: contentDisposition, }); const presignedUrl = await getSignedUrl(s3, command, { expiresIn: 900 }); const expiresAt = new Date(Date.now() + 900 * 1000).toISOString(); return respond(200, { presignedUrl, expiresAt }); } catch (err) { console.error("Preview error:", err); return respond(502, { error: "Unable to generate preview link. Please try again." }); } }; function respond(statusCode, body) { return { statusCode, headers: { "Content-Type": "application/json", "Access-Control-Allow-Origin": "*", }, body: JSON.stringify(body), }; }

5.3 uploadFile

📄 index.mjs
import { S3Client, PutObjectCommand } from "@aws-sdk/client-s3"; import { getSignedUrl } from "@aws-sdk/s3-request-presigner"; const s3 = new S3Client({}); const BUCKET_NAME = process.env.BUCKET_NAME; export const handler = async (event) => { try { let body; try { body = event.body ? JSON.parse(event.body) : event; } catch { return respond(400, { error: "Invalid request body." }); } const { zendeskId, fileName, contentType, zendeskTicketCreateDate } = body; if (!zendeskId || !zendeskId.trim()) { return respond(400, { error: "zendeskId is required." }); } if (!fileName || !fileName.trim()) { return respond(400, { error: "fileName is required." }); } const safeFileName = fileName.trim().replace(/[\/\\]/g, "_"); const s3Key = `${zendeskId.trim()}/${safeFileName}`; const metadata = { "zendesk-id": zendeskId.trim(), }; if (zendeskTicketCreateDate) { metadata["zendesk-ticket-create-date"] = String(zendeskTicketCreateDate); } const command = new PutObjectCommand({ Bucket: BUCKET_NAME, Key: s3Key, ContentType: contentType || "application/octet-stream", Metadata: metadata, }); const uploadUrl = await getSignedUrl(s3, command, { expiresIn: 900, unhoistableHeaders: new Set( Object.keys(metadata).map(key => `x-amz-meta-${key}`) ), }); return respond(200, { uploadUrl, s3Key, fileName: safeFileName, }); } catch (err) { console.error("Generate upload URL error:", err); return respond(502, { error: "Unable to generate upload URL. Please try again." }); } }; function respond(statusCode, body) { return { statusCode, headers: { "Content-Type": "application/json", "Access-Control-Allow-Origin": "*", "Access-Control-Allow-Headers": "*", "Access-Control-Allow-Methods": "OPTIONS, POST", }, body: JSON.stringify(body), }; }

5.4 deleteFile

📄 index.mjs
import { S3Client, DeleteObjectCommand } from "@aws-sdk/client-s3"; const s3 = new S3Client({}); const BUCKET_NAME = process.env.BUCKET_NAME; export const handler = async (event) => { try { let body; try { body = event.body ? JSON.parse(event.body) : event; } catch { return respond(400, { error: "Invalid request body." }); } const { zendeskId, s3Key } = body; if (!zendeskId || !s3Key) { return respond(400, { error: "zendeskId and s3Key are required." }); } const expectedPrefix = `${zendeskId}/`; if (!s3Key.startsWith(expectedPrefix)) { return respond(403, { error: "Invalid file reference." }); } const command = new DeleteObjectCommand({ Bucket: BUCKET_NAME, Key: s3Key, }); await s3.send(command); return respond(200, { success: true, deletedKey: s3Key }); } catch (err) { console.error("Delete error:", err); return respond(502, { error: "Unable to delete file. Please try again." }); } }; function respond(statusCode, body) { return { statusCode, headers: { "Content-Type": "application/json", "Access-Control-Allow-Origin": "*", }, body: JSON.stringify(body), }; }

6. Set Up API Gateway

Step 1 Navigate: Services → API Gateway → Create an API.

Step 2 Choose REST API (not HTTP API).

Step 3 Fill in API Name: data-migration-api → click Create API.

Step 4 Click Create Resource.

Step 5 Fill in Resource Name: files, enable CORS, click Create Resource.

Step 6 With /files selected, click Create Method.

  • Method Type: GET
  • Integration Type: Lambda function
  • Lambda Proxy Integration: Enable
  • Lambda function: listFilesForRecord

Click Create method.

Step 7 Create a DELETE method for /files with Lambda deleteFile.

Step 8 Create two more resources under /files:

  • /files/preview → POST → Lambda previewFile
  • /files/upload → POST → Lambda uploadFile

Step 9 Click Deploy API. Select New Stage, name it Deployment, click Deploy.

Step 10 Copy the Invoke URL — you'll need it for Salesforce.

🔗 API Gateway – Deployment Stage & Invoke URL

7. Generate API Key

Step 1 In API Gateway, click API Keys → Create API Key.

Step 2 Name: salesforce-key → select Auto generate → click Save.

Step 3 Copy the API Key and store it securely for Salesforce setup.
